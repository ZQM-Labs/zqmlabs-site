**Start with the experience, then decide whether you need to become a host.**
ZQM Labs uses a browser-first six-stop puzzle format with QR or
manual-code alternatives and an offline-first player design. A
published example pack and a working demo are *not* evidence that a
venue-specific paid event is currently available.

## 1. See how a quest feels

[Open the Wisp's Lost Lanterns browser demo](/games/hunt-for-wisps/play/?demo=1)
to explore the story and puzzle mechanics. The demo is separate from
the downloadable public sample, and network/device support varies.
You do not need to buy an event package to read the public game format.

If your goal is to organize a public outdoor event, **do not** treat
the demonstration's fictional/default stops as permission to install
signs or send groups to a private location.

## 2. Study a real six-stop content example

The [Wisp's Warm-Up free sample](https://github.com/ZQM-Labs/quest-packs/tree/main/sample-quest)
contains a public six-stop JSON file with stories, puzzles, hint ladders,
fallbacks and example coordinates. It is a starting point for learning
and authorized adaptation; it is not a route verified in every
neighborhood.

The [first-quest writing tutorial](https://github.com/ZQM-Labs/quest-authoring/blob/main/guide/write-your-first-quest.md)
walks you through validating the pack, finding suitable approved
stops and preparing a separate QR-sign configuration. It explains
which example generator outputs are organizer-only previews that
must not be published as secure player content.

## 3. Decide what kind of host you are

| Planning question | Practical next step |
| --- | --- |
| Is this for a school or museum? | Confirm student supervision, venue rights, age suitability and an accessible non-GPS route |
| Is this for staff or friends? | Choose safe cooperative or staggered team starts, never a street chase or public live location feed |
| Is this for a city or visitor group? | Confirm local history sources, sign and venue permissions, public accessibility and community review |
| Do I need a seasonal event? | Use the static host-run [Community Day planning tools](https://github.com/ZQM-Labs/organizer-toolkit/tree/main/event-kit), not an assumed active booking or server timetable |

Every actual kit requires **six permitted stops**, specific verified
puzzles, a matching player/QR setup and a documented field test.
Teams should be able to finish safely without speed-based rewards.
Allow no-photo alternatives and obtain consent for any sharing.

## 4. How do I know the pack is ready?

A good first host review covers the pack/validator result, physical
route and signage, screen-reader/keyboard and mobile usability,
camera/GPS permission denial, offline recovery, weather and safe
crossings. Record exact versions and observed outcomes in the
[playtesting process](https://github.com/ZQM-Labs/playtests).
Passing a JSON validator does **not** certify venue safety or release.

## 5. Explore a custom event with ZQM Labs

For a proposed neighborhood, heritage, school, nonprofit or workplace
pilot, send [an organizer inquiry](mailto:zqmcomputing@gmail.com)
with your organization's purpose, venue/city, approximate teams,
proposed dates, supervision and accessibility needs, and whether
venue permissions are already arranged. Do not send student rosters,
private home addresses, attendee coordinates or paid access codes.

A conversation is **not** a confirmed booking. Custom authorship,
service area, event support, pricing, licensing and any checkout
or fulfillment require a separate scoped agreement.
