- The preview Hugo site syncs exact production player source `739a8490c0c1ce5df5f8e6c8b5ce57033ccc7749`. Player `app.js` and `sw.js` are byte-identical to the archived publisher production release.

- `public/games/lantern-player/tools/` and `public/games/lantern-player/README.md` were eliminated from the build without removing the legacy route or its runtime entry; new CI tests fail if these development files reappear.
- Six new sitemap destinations are explicit: `/labs/`, `/computing/`, `/computing/inquiry/`, and three Computing services. None of the **40** production sitemap destinations is missing.

## Unresolved differences: fail production release

1. **40 removed files:** includes **36 media assets** under `img/`, `images/`, and `video/`, plus `apple-touch-icon.png`, `favicon.ico`, `js/countdown.js` and **`release-manifest.json`**. The latter is generated by the publisher/release path, not necessarily the plain Hugo job. Do **not** fabricate a release manifest inside the preview.
2. **46 byte-changed files:** includes HTML for the homepage, game directory, guides, legal/contact/offer routes, index feeds and sitemap, plus `favicon.svg`. Route-name parity is not content, metadata or behavioral parity. Review each public price, disclaimer, translation, canonical, image/CTA and outbound link difference before approval.
3. **70 added files:** includes six new HTML routes, two section XML feeds, the isolated Daily Geo Mystery experiment, a large legacy Lantern Player runtime tree and a revised illustration. Additional runtime files were **not** present in the archived publisher ZIP. Confirm that every added legacy runtime file is intended for public distribution, is licensed and is compatible with older service workers. Do not approve the whole tree merely because its directory is not named `private`.
4. **Legacy `/games/` ownership:** preview now renders authored directory content, but `games/index.html` is not byte-identical to the publisher baseline; preserve visible statuses and CTA behavior, then reconcile approved content deltas.
5. **Missing live evidence:** no real CDN HTTP/CSP/redirects/SEO crawl, accessibility/device test, warm-cache upgrade on the composite candidate, purchase→entitlement→inbox fulfillment verification, or rollback demonstration.
