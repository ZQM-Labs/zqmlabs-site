## Answer-first structure for marketing guides

1. Start with a precise 40–80-word answer to the reader's question.
2. Show a concrete procedure, comparison, game demonstration, or organizer checklist.
3. Include limits: permissions, safe access, disability accommodations, age suitability, and current product status.
4. Link to the most relevant original game page, demo, or organizer/contact path.
5. Avoid mass-produced city variants, fabricated testimonials, FAQ rich-result promises, and claims of worldwide event fulfillment.

## Measurement and gating

- Baseline Google Search Console and Bing Webmaster Tools before setting rank or traffic targets.
- Track the landing page, organic source, demo-start event, meaningful demo completion, and *qualified host inquiry* separately.
- Report conversions using aggregated, privacy-respecting measures; avoid collecting precise location traces as SEO telemetry.
- Validate rendered title, descriptions, canonical, social metadata, JSON-LD, internal links and sitemap in CI; keep unreleased/private routes out of public indexes.
- Production remains controlled by the independently pinned deployment source. This document does not authorize releases or checkout claims.
