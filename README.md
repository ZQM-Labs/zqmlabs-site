# zqmlabs.com — ZQM Labs public website

The public website for **ZQM Labs — Z's Quests & Mischief**: self-guided,
location-based scavenger-hunt games for communities, schools, and offices
in Volusia County, Florida. *Games, gear & a little mischief.*

This repo is the deployment source for https://zqmlabs.com (Hugo, built
and served by GitHub Pages). Content is authored in the ZQM monorepo and
synced here for publication.

- Play the free demo: https://zqmlabs.com/games/hunt-for-wisps/
- Book a kit or ask a question: zqmcomputing@gmail.com

## Build locally

```bash
hugo --gc --minify   # Hugo extended, produces ./public
```
